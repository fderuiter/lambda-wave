# Change Control Record

**CCR ID:** CCR-20260713-091700
**Version:** Implement non-blocking tryWriteAudit API

## Problem Description
Real-time patient safety loops suspend due to log queue saturation, failing execution deadlines under heavy load.

## Proposed Change
Implement a non-blocking `tryWriteAudit` API with fallback diagnostic warnings to stderr. Drop log entry instead of blocking.

## Impact on Hazards
Mitigates H-SYS-013. Dropping logs is preferred to suspending safety critical loops.

## Quality Policy Origin
ISO 13485 Clause 7.1

## Verification Strategy
Automated tests and manual testing of heavy telemetry load without real-time thread suspension.
