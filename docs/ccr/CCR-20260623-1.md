# Change Control Record

**CCR ID:** CCR-20260623-1
**Version:** HEAD

## Problem Description
Parallel tests executing simultaneously face IPC socket conflicts due to shared static socket paths. Audit tests timeout due to inefficient size calculation. Watchdog tests jitter due to coarse polling.

## Proposed Change
Make IPC paths dynamic using process IDs. Optimize byte length calculation in audit chunk generation. Reduce watchdog test polling to 2ms.

## Impact on Hazards
Impacts H-SYS-001 and Watchdog Timeouts. We also introduce H-SYS-006 to capture parallel test execution interference. The changes address performance and reliability of the testing framework without altering production system behaviour under single-execution. 

## Quality Policy Origin
ISO 13485 Clause 7.3.6

## Verification Strategy
The changes are verified by the automated test suites: sgrt-radar-system-test, watchdog-check, and audit-check.
