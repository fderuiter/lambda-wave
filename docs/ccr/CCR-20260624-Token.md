# Change Control Record

**CCR ID:** CCR-20260624-Token
**Version:** Native-First Hardening

## Problem Description
The external `uuid` dependency was identified as a vestigial component that increased Software of Unknown Provenance (SOUP) footprint and audit overhead.

## Proposed Change
Removed the external `uuid` library and introduced a native token generation module at `src/Safety/Token.hs` to centralize session and identifier generation using high-entropy system sources.

## Impact on Hazards
Impacts H-SYS-007. By replacing the external UUID generator with a native, standardized implementation in `Safety.Token`, we reduce external supply chain risks and ensure all components utilize consistent, secure randomness sources to mitigate the risk of session token collisions or hijacking.

## Quality Policy Origin
ISO 13485 Clause 7.3.3 (Design and Development Inputs) - Minimizing external SOUP components to reduce regulatory and security risks.

## Verification Strategy
Verified by successful compilation without the external `uuid` modules and ensuring the Web UI session management functions correctly. CCR CI tests pass and SOUP analysis document has been appropriately updated to archive the library.
