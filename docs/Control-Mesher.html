fitPolynomialSurface :: [Point3D] -> [Double] #

Fits a polynomial surface to the points Model: z = c0 + c1*x + c2*y + c3*x^2 + c4*xy + c5*y^2 Uses leastSquares for dependency-free calculation.

Complexity: O(N * M^2) where N is points, M is 6 terms.
