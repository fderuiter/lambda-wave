Description

Provides basic Matrix operations using standard Lists to satisfy Class C compliance (removing external dependencies like hmatrix/vector).

Warning: This is O(N^3) and uses linked lists. Intended for small matrices (N < 10).

transpose :: [[a]] -> [[a]] #

The transpose function transposes the rows and columns of its argument. For example,

>>> transpose [[1,2,3],[4,5,6]]
[[1,4],[2,5],[3,6]]

If some of the rows are shorter than the following rows, their elements are skipped:

>>> transpose [[10,11],[20],[],[30,31,32]]
[[10,20,30],[11,31],[32]]

For this reason the outer list must be finite; otherwise transpose hangs:

>>> transpose (repeat [])
* Hangs forever *
