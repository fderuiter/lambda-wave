# Change Control Record

**CCR ID:** CCR-20260701-085000
**Version:** HEAD

## Problem Description
Background loops such as the watchdog or audit loop must never fail silently. Currently, the system risks entering an undefined state where the therapeutic beam remains active while the monitoring processes have crashed.

## Proposed Change
Introduce a centralized thread supervision utility (`Safety.Thread`) to eliminate "zombie" processes. Background threads are wrapped in a standardized supervisor ensuring a "fail-stop" posture.

## Impact on Hazards
Impacts H-SYS-009. This change mitigates the risk of silent thread failures by ensuring that if any core safety process crashes, the entire system triggers a global shutdown within 50ms.

## Quality Policy Origin
ISO 13485 Clause 7.3

## Verification Strategy
Automated tests verify that any simulated crash in a supervised thread results in the triggerShutdown routine being called immediately. Performance-critical loops retain their affinity to OS threads.
