# Change Control Record

**CCR ID:** CCR-20260714-365
**Version:** PR-365

## Problem Description
The watchdog thread's local error-handling block intercepted and masked all exceptions, including critical runtime crashes. This hid failures from the central safety supervisor, leaving the system running in an indeterminate state, relying on multi-second hardware fallbacks.

## Proposed Change
Modified the watchdog thread to log the error and then rethrow the exception (`throwIO`), ensuring that the exception propagates up to the central safety supervisor immediately to trigger a global shutdown.

## Impact on Hazards
Impacts H-SYS-014 (Watchdog thread exception masked) and H-SYS-009 (Silent thread failure). Ensures that a crash in the watchdog thread correctly triggers the safety supervisor to execute a global shutdown, rather than leaving a zombie process.

## Quality Policy Origin
ISO 13485:2016 Clause 7.3.9 (Control of design and development changes).

## Verification Strategy
The change will be verified by automated tests simulating a watchdog crash and confirming immediate central supervisor shutdown, and manual code review to ensure `throwIO` propagates out of the watchdog loop.
